# 0026 — Evals reales: casos 06–09, `evals.sh` y comparador

Fecha: 2026-11-25

Decisión: cuatro casos nuevos en `plugins/lf/evals/06..09-*` sobre tareas reales (bug Symfony con test, componente Vue, N+1, cambio de lógica sin test), cada uno con un `scaffold.sh` que monta un mini repo sintético y graders deterministas en `case.yaml` (esquema 1.1: `regex` sobre el contenido del fichero final, `tool_used` con `input_match`, `file_exists`). `scripts/evals.sh` lanza un `claude plugin eval` por caso (`--runs 2`, tope total 5 USD repartido, sin ablación) y `scripts/evals-compare.mjs` añade una línea a `plugins/lf/evals/results/summary.jsonl` (ignorado por git) y la compara con la anterior de la misma selección. Lo lanza el mantenedor: gasta tokens, no va en CI ni en `test-hooks.sh`; el comparador sí tiene tests con JSON sintéticos (`tests/evals-compare.test.mjs`).
Regresión: score de un caso baja >0,10 o caso nuevo en 0 (con histórico previo) → exit 1; coste total >+30 % solo avisa. Una regresión o un run parcial **no se registran** (la referencia no baja); los casos con runs en `error` se omiten (exit 2). Sin histórico → exit 0.
Desvíos respecto al contrato: (1) los casos no llevan `Bash`: con `~/.docker/contexts` como enlace (WSL + Docker Desktop) el eval se niega a arrancar, así que el agente razona el test y cierra con `Hecho cuando:`; (2) sin `check.sh` de fallback, un grader `{ source: file }` basta; (3) `--case` solo admite `*`, por eso un eval por caso; (4) el caso 09 mide **conducta** (edita el servicio y amplía el test), no el bloqueo del hook `Stop`, porque el eval no carga `~/.claude/lf` y el hook nunca bloquea; el bloqueo lo cubren `tests/gate-cases.tsv` y `test-hooks.sh`.
Lecciones de diseño: un grader sobre el arreglo exige una forma correcta (con `strict_types`, `round()` necesita cast), no una subcadena, pero acepta las equivalentes: en la primera pasada real el agente escribió `intdiv($cents * $percent + 50, 100)`, correcto, y un grader solo con `(int) round(` lo suspendía; el test intacto se comprueba fila a fila; la negación se escribe con lookahead `^(?!…)[\s\S]*$` + `match: contains`.
Límites: los casos salen 1,00 a la primera y pueden no discriminar; `--baseline` (with-without, ~2x coste) mide si el plugin aporta. Sin bucle de automejora ni cruce con telemetría (H5). Los cinco casos de ADR 0019 no cambian (`--all` los incluye).
Descartado: runner propio con `claude -p` (más código y sin baseline); solo LLM sobre el mensaje (no prueba el arreglo); versionar el histórico (ruido por release); umbral «cualquier bajada» (falsos positivos con la varianza del modelo).
