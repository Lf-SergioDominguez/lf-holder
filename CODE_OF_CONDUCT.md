# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/) como código de conducta para issues, discusiones, PR y cualquier otro espacio del proyecto.

En resumen: trato respetuoso, críticas al código y no a las personas, cero acoso o lenguaje discriminatorio, y nada de publicar datos privados de otros.

## Cómo reportar

Si presencias o sufres un comportamiento inaceptable, usa el menú **⋯ → Report content** del comentario, issue o PR y elige *Report to repository admins*: el aviso llega en privado al mantenedor. Los reportes se tratan con confidencialidad. Las medidas posibles van desde un aviso hasta el bloqueo en el repo, según las pautas de aplicación del Contributor Covenant.
